Sales Analytics Dashboard using Power BI
Project Overview

This project is an interactive Sales Analytics Dashboard developed in Power BI.

The dashboard helps analyze sales performance, profitability, product performance, promotions, and sales trends through multiple interactive reports.

Business Requirements Implemented
1. Top/Bottom 5 Products Analysis
Top 5 Products by Sales
Bottom 5 Products by Sales
Top 5 Products by Profit
Bottom 5 Products by Profit
Top 5 Products by Quantity Sold
Bottom 5 Products by Quantity Sold
2. Sales Trend Analysis

Sales trends are analyzed over different time periods using interactive visualizations.

3. Sales vs Profit Analysis

Scatter plot visualization showing the relationship between sales and profit.

4. Period Comparison

Users can compare Sales, Profit and Quantity Sold between different periods.

5. Promotion Analysis

Average discount offered under different promotion categories.

6. Order Analysis

Total number of orders and detailed order-level information.

7. Interactive Filtering

Dashboard can be filtered using:

Product
Date
Customer ID
Promotion Category
8. Geographic Analysis

Sales performance by city using map visualization.
